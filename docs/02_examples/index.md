::: tip Teleportation

**TypeScratcher** ロゴをクリックするとエンジン起動します。<br>

次に **緑の旗マーク**をクリックするとゲームが始まります。<br>

スライムを矢印キー（上下左右）で移動させ、**ドア**に入ると、**ケージ**へテレポートします。<br>

テレポートするたびに変数 **Count** がカウントアップします。

:::
